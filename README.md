# PlayWhe Pro - Play Store Release
Builds SIGNED APK + AAB automatically.

1. Create repo at github.com/new - name playwhe-pro-release - Public
2. Upload ALL files from this zip
3. Go to Actions tab - wait 3-4 mins
4. Download artifacts: APK + AAB + KEYSTORE

IMPORTANT: Save keystore file - needed for all future updates!
For Play Store: upload the .aab file to play.google.com/console

App: com.playwhe.pro - PlayWhe Pro v1.0.0
